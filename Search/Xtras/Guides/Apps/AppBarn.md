**AppBarn: The Archive for Files, Softwares and Tools**

**Steps**
1. Locate and open the AppBarn folder located in Search/Apps/AppBarn
2. Create folders each representing a category e.g. Game Saves, Trainers, Tools 
3. Add files and compress them into zip format
4. Add compressed files into related categories 
5. Navigate to AppBarn in the dashboard, categories will be displayed
6. Click on a category and search through it using the provided search bar
7. Click to download the compressed files
